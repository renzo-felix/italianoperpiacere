8. SISTEMA DE AUDIO (ippAudio / ippVoice) — ODOO-SAFE
══════════════════════════════════════════════════════════════════════════

── PROBLEMA CENTRAL EN ODOO ──
Odoo usa DOMEval para inyectar scripts. DOMEval envuelve el código en
una función local:
  (function() { /* tu código aquí */ })()

Consecuencia: `function foo()` declarada DENTRO del código queda en el
scope LOCAL de esa función, NO en window. Los onclick="foo()" buscan en
window y tiran "foo is not defined".

Solución: Exponer explícitamente a window: `window.foo = foo;`

── BLOQUE DE AUDIO ESTÁNDAR ──
Este bloque va AL INICIO del <script>, ANTES de cualquier execution guard.
Tiene su propio guard (window.__ippVC) para ejecutarse solo una vez.

```javascript
// ── IPP Voice Preloader (Odoo-safe, una vez por sesión) ──
if (!window.__ippVC) {
  window.__ippVC = true;
  window.__ippV = [];
  if (window.speechSynthesis) {
    var _ld = function() {
      var v = speechSynthesis.getVoices();
      if (v && v.length) window.__ippV = v;
    };
    speechSynthesis.onvoiceschanged = _ld;
    _ld(); setTimeout(_ld, 100); setTimeout(_ld, 600); setTimeout(_ld, 1500);
  }
}
```

── FUNCIÓN ippVoice (selección de voz por género) ──
```javascript
function ippVoice(gender) {
  var voices = (window.__ippV && window.__ippV.length)
    ? window.__ippV
    : (window.speechSynthesis ? speechSynthesis.getVoices() : []);
  var itV = voices.filter(function(v) { return v.lang && v.lang.startsWith('it'); });
  if (!itV.length) return null;
  var voice = null;
  if (gender === 'm') {
    voice = itV.find(function(v) { return /cosimo|luca|giorgio|male|masc/i.test(v.name); });
    if (!voice) voice = itV.find(function(v) { return !/elsa|alice|giulia|female|femm/i.test(v.name); });
  } else {
    voice = itV.find(function(v) { return /elsa|alice|giulia|female|femm/i.test(v.name); });
    if (!voice) voice = itV.find(function(v) { return !/cosimo|luca|giorgio|male|masc/i.test(v.name); });
  }
  return voice || itV[0];
}
```

Lógica de ippVoice:
  1. Intenta match positivo por nombre (cosimo/luca/giorgio para M, elsa/alice/giulia para F)
  2. Si falla, usa match negativo (para F: voz que NO sea M, y viceversa)
  3. Fallback: primera voz italiana disponible
  4. Siempre usa el cache window.__ippV con fallback a getVoices() en vivo

── FUNCIÓN ippAudio (firma estándar, módulos 1-16) ──
```javascript
function ippAudio(text, rate, gender) {
  rate = (typeof rate === 'number' && isFinite(rate) && rate > 0) ? rate : 0.82;
  gender = (gender === 'm' || gender === 'f') ? gender : 'f';
  if (!window.speechSynthesis) return;
  try { speechSynthesis.cancel(); } catch(e) {}
  var utt = new SpeechSynthesisUtterance(String(text));
  utt.lang = 'it-IT'; utt.rate = rate;
  var voice = ippVoice(gender);
  if (voice) utt.voice = voice;
  (function(u) {
    setTimeout(function() {
      try { speechSynthesis.speak(u); } catch(e) {}
    }, 60);
  })(utt);
}
```

⚠️  modulo_0/etapa2 tiene firma diferente: ippAudio(text, onStart, onEnd)
    con callbacks para encadenar líneas del diálogo. NO cambiar esa firma.

── EXECUTION GUARD ──
Odoo puede re-ejecutar el script al navegar entre slides.
Para evitar doble-ejecución y errores de re-declaración:

```javascript
if (!window.__ipp_mX_eY__) {   // X = módulo, Y = etapa
  window.__ipp_mX_eY__ = true;

  // ... todo el código del módulo aquí ...

  // AL FINAL: exponer funciones a window
  window.ippAudio       = ippAudio;
  window.playLine       = playLine;
  window.playAllDialog  = playAllDialog;
  window.checkOpt       = checkOpt;
  window.toggleCulture  = toggleCulture;
  // ... cualquier función usada en onclick, oninput, onchange

} // end execution guard
```

Naming convention de guards:
  modulo_0/etapa2 → window.__ipp_m0_e2__
  modulo_1/etapa3 → window.__ipp_m1_e3__
  etc.

── REGLA: TODO onclick DEBE ESTAR EN window ──
Si un atributo HTML tiene onclick="foo(...)", la función foo DEBE estar
en window. Para hacerlo: colocar `window.foo = foo;` antes del cierre
del execution guard.

── USO DE var vs let/const ──
Dentro de execution guards: preferir var. let/const no pueden ser
re-declarados si el guard falla y el script corre dos veces.

── ESTRUCTURA COMPLETA DE UN <script> ──

15. COSAS A RECORDAR / ERRORES COMUNES
══════════════════════════════════════════════════════════════════════════

1. NUNCA usar fondo negro. --black solo para texto.
2. NUNCA onclick="speak(...)" — el nombre de Odoo tiene speak() propio.
   Siempre usar onclick="ippAudio(...)"
3. SIEMPRE exponer funciones a window dentro del execution guard.
4. SIEMPRE poner el IPP Voice Preloader ANTES del execution guard.
5. onvoiceschanged = function(){ speechSynthesis.getVoices(); } NO cachea nada — NO usar.
6. speechSynthesis.cancel() seguido inmediatamente por speak() puede fallar.
   Siempre usar setTimeout(60ms) antes del speak().
7. let/const dentro de execution guards pueden causar SyntaxError si el
   script corre dos veces. Usar var.
8. El embed de YouTube debe ser /embed/ID no /watch?v=ID
9. Los giorni della settimana llevan acento: lunedì, martedì, mercoledì,
   giovedì, venerdì (sabato y domenica sin acento).
10. Los nombres de las unidades deben ser CONSISTENTES en las 4 etapas.
11. Los artículos (ARTICOLI) son tema crítico A1 — incluirlos en M2/M3.
12. Contenido NO debe ser exclusivamente del video/input — integrar A1 general.
13. checkFill(input) — el oninput debe pasar 'this', no el evento.
14. En Odoo, DOMContentLoaded puede no dispararse correctamente.
    Preferir inicialización directa o setTimeout(() => init(), 0).
