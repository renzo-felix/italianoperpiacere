## DESCRIPCIÓN PARA EL DOCENTE

Este video introductorio de LearnAmo sirve como puente entre el nivel A1 y A2. Francesca repasa las estructuras clave del A1 (presentaciones, verbos ser/estar, presente, passato prossimo básico) y presenta el vocabulario del aula y las instrucciones típicas de clase. Ideal como activador de conocimientos previos y para establecer el tono del nuevo curso.

**Duración aproximada:** 8–12 minutos
**Idioma del video:** Italiano con subtítulos disponibles
**Fragmento recomendado:** Completo, o del minuto 0:00 al 6:00 para la parte de repaso

---

## TEMAS QUE TRABAJA ESTE RECURSO

- Vocabulario del aula (oggetti della classe)
- Istruzioni per i compiti (apri, chiudi, leggi, ascolta, scrivi, ripeti, abbina…)
- Ripasso: presentarsi, nazionalità, professioni, numeri
- Motivación para continuar el aprendizaje del italiano
